# i32

[← Library Index](README.md) · Source: [lib/i32.ir4](../../lib/i32.ir4)

32-bit signed division and modulo fallbacks (auto-required when i32/ or i32mod is used)

## Functions

- **i32/** ( a :i32 b :i32 -> :i32 ) — Signed 32-bit truncating division: *a* / *b*
- **i32mod** ( a :i32 b :i32 -> :i32 )

  Signed 32-bit remainder (sign matches dividend *a*): *a* mod *b*

## Platform Specifics

### 6502

6502 32-bit integer primitives for IR4th.
Preserves X (IR4th data stack pointer). Uses ZP $02..$10.

### 65816

32-bit multiply, divide, modulo, and shifts for 65816

### z80

Z80 32-bit integer primitives for IR4th.
Uses SP/IX/IY stack scratch (zero relocations).
